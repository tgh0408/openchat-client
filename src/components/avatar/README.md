# 头像组件

## 位置与职责

- 源码位置：`src/components/avatar/`。
- 界面位置：登录账号、左侧个人头像、会话列表、通讯录、消息行、设置及托盘预览。

## 文件说明

| 文件                                           | 功能与使用位置                                                                             |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------ |
| [AvatarImage.vue](AvatarImage.vue)             | 通用头像图片，加载失败回退默认头像；用于登录、导航、联系人选择、好友列表、设置和托盘等位置 |
| [GroupAvatar.vue](GroupAvatar.vue)             | 使用最多九位成员头像拼接群头像；用于会话行、通讯录群列表及详情、托盘预览                   |
| [ChatContactAvatar.vue](ChatContactAvatar.vue) | 聊天和历史消息行中的联系人头像；进入可见区域时通知调用方加载资料，点击通知刷新             |

## 调用关系

[消息列表](../chat/messages/README.md) 与 [历史页面](../../pages/history/README.md) 使用消息头像。
[工作台](../../pages/workspace/README.md) 和 [托盘预览](../../pages/tray-preview/README.md) 复用普通及群头像。
资料查询由调用方处理，头像组件不把 roomId 当作用户 UID，也不自行创建资料缓存。
