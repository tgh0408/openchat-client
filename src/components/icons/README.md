# 公共图标

## 位置与职责

- 源码位置：`src/components/icons/`。
- 界面位置：工作台、图片预览和通话窗口的工具按钮。

## 文件说明

| 文件                                     | 功能与调用位置                                                    |
| ---------------------------------------- | ----------------------------------------------------------------- |
| [PinIcon.vue](PinIcon.vue)               | 窗口置顶图标；由工作台标题栏、图片预览和通话面板使用              |
| [RtcSpeakerIcon.vue](RtcSpeakerIcon.vue) | 根据 `enabled` 展示扬声器开启或关闭状态；由通话面板和设备菜单使用 |

图标仅负责展示，按钮事件、窗口置顶及音频状态变更由调用方负责。
