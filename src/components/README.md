# 公共组件

## 位置与职责

- 源码位置：`src/components/`，存放跨页面复用的界面组件及其配套逻辑。
- 界面位置：由调用页面决定，覆盖头像、聊天消息、输入区、联系人选择及操作反馈。
- 页面入口在 [pages](../pages/README.md)，完整两端定位见 [项目结构](../../docs/project-structure.md)。

## 子目录

| 目录                                 | 功能与使用位置                             |
| ------------------------------------ | ------------------------------------------ |
| [avatar](avatar/README.md)           | 登录、导航、会话、通讯录和历史中的头像展示 |
| [avatar-crop](avatar-crop/README.md) | 注册流程中的头像裁剪编辑器                 |
| [chat](chat/README.md)               | 工作台、独立聊天和历史中的消息及输入组件   |
| [contacts](contacts/README.md)       | 群聊详情中的联系人选择弹窗                 |
| [icons](icons/README.md)             | 窗口置顶和通话扬声器状态图标               |

## 维护边界

组件通过属性、事件或既有服务参与页面流程，不直接访问 Electron 数据库或任意文件路径。
页面专属逻辑仍放在对应 `src/pages/` 目录。工具生成的 `.cache/` 不属于组件源码，不纳入本目录文档索引。
