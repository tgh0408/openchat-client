# 独立聊天窗口

## 位置与职责

- 源码位置：`src/pages/conversation/`。
- 界面位置：会话右键“独立窗口显示”或将会话拖出主窗口后打开的单会话窗口。
- 加载入口：`#conversation`。

## 文件说明

| 文件                                             | 功能                                                               |
| ------------------------------------------------ | ------------------------------------------------------------------ |
| [ConversationWindow.vue](ConversationWindow.vue) | 读取主进程绑定的会话上下文，加载独立模式工作台，处理加载失败和关闭 |

## 调用关系

复用 [ChatWorkspace.vue](../workspace/ChatWorkspace.vue) 的消息及输入流程，
不是另一套聊天组件。原生控制及桥接位于 `electron/pages/conversation/`。
不自行恢复账号、初始化内容库或建立第二条 SSE；权限限于绑定会话，聊天详情侧栏在独立模式下禁用。
