# 滚动截图

## 窗口吸附

Windows 普通截图支持顶层窗口吸附：鼠标悬停预览窗口边界，首次左键单击只锁定方框，锁定后显示随选区定位的工具栏，保留确认、取消按钮及滚动截图等工具；左键双击或点击确认按钮完成截图并返回图片草稿，右键或取消按钮取消截图。悬停预览阶段不显示工具栏。按住左键拖动超过阈值时改为自由框选，松开后保留选区供移动、缩放或使用工具；单击选区、拖动或缩放结束均不会直接确认截图。Enter 和 Escape 仍分别用于确认和取消，确认不会自动发送消息。

主进程在显示截图遮罩前按前后层级采集本次窗口边界，通过 DWM 可见边框避开不可见的缩放边缘；过滤截图遮罩、最小化窗口、隐藏窗口、其他虚拟桌面上的 cloaked 窗口和桌面外壳。只向当前截图页面传递归一化矩形，不暴露窗口句柄、标题或原生控制接口。候选随本次屏幕快照固定，任务结束后清除；原生识别不可用或非 Windows 平台仍可手动框选。

窗口边界先与每个显示器的物理像素范围求交，再转换为该屏幕的选区，支持负坐标及不同缩放比例。跨屏窗口只选择当前屏幕内的部分，不拼接多屏；最终仍裁剪屏幕快照，被遮挡内容不会还原。异形或透明窗口按矩形外框处理，不识别窗口内控件。

## 滚动操作

框选后点击“滚动截图”，将鼠标移入选区，向上或向下滚动。程序在采样后立即尝试匹配并更新长图，不要求停下滚轮后再等待画面稳定；回滚到已有内容时只更新定位，不重复追加或截短长图。可以从页面中间开始，分别向两端扩展。

单击选区外遮罩或预览面板结束采集，尾帧确认后直接返回原会话的图片草稿并沿用剪贴板复制流程，不再打开二次确认页，不自动上传或发送。Escape 取消整个截图任务；方向键和滚轮仍交给原窗口，回车不结束采集。预览不再提供点击定位原页面功能。

## 来源与移植范围

拼接核心参照 [jietuba](https://github.com/1003129155/jietuba) 的 `rust_libs/longstitch/src/hash.rs`、`lcs.rs`、`session.rs`，固定参考提交为 `329dea1c6bcd1601a6c9c0689fac7934f61dd2d4`。上游版权为 Copyright (c) 2025 JYAARU，采用 MIT 许可；完整许可证位于 `public/licenses/jietuba-MIT.txt`，由 Vite 复制到 `dist/licenses/`，随应用分发。

这里是适配 Electron 的 TypeScript 移植，没有加载 Python 扩展、Rust 二进制或上游依赖。当前实现纵向手动滚动、双向增量拼接、回滚定位、固定栏处理及实时缩略图；未移植横向截图、自动注入滚轮、裁剪工具、钉图或其他截图工具，不宣称整款应用或所有场景完全等价。

与上游相比，行指纹使用 JavaScript 可精确表示的 53 位双指纹，平均色编码为三通道各 5 位；不是原 Rust 的 64 位哈希。连续公共行段按位移保留最长候选再选取最多 32 个，限制重复行带来的候选存储；不承诺候选顺序与上游每个输入都一致。额外保留完全相同帧的原位置，避免空白页在方向提示下被重复追加。

## 匹配与合成

- 默认走受 wayscrollshot 列采样思路启发的独立 TypeScript 快速实现（`screenshot-features.ts`、`screenshot-columns.ts`）：每行读取三组三列，转换为灰度组均值。特征提取为 `O(9H)`，不预先计算完整哈希或逐帧规范整幅图的 alpha。
- 先按上次位移附近排列候选，再检查唯一采样行提出的其他位移。至少需要六条唯一行证据，且分散覆盖重叠区；最多检查 32 个可信候选，每个候选最多取 96 行计算三组 MAD。不遍历全部位移乘上全部重叠行。
- MAD 接近的多个候选、空白或重复采样列不能直接接长。候选还需通过三个纵向区间、五个横向位置的 RGB 像素块复核，并在接缝处检查少量完整 RGB 行。固定栏边缘无法确认时回退，不强行选择接缝。
- 快速复核失败后，才计算当前帧完整行指纹并回到原增量定位算法：先精确指纹，再用有唯一行证据的平均色匹配；先查邻近范围，必要时搜索已有长图。第一次回退可能计算之前尚未建索引的旧片段，之后按像素片段缓存复用，不通过合并整张长图取得哈希。
- 原始像素按段保存；局部复核通过行索引只读取所需行，预览仍只采样可见片段。alpha 仅在保存新增像素时规范为不透明；复制新内容和维护已有长图的轻量行索引仍有成本，不能把整条截图链路都称为 `O(9H)`。
- 快速路径的局部复核不能从数学上证明所有未采样像素都一致。特殊重复布局、动态覆盖和细微内容变化仍需人工检查；本实现通过证据不足即回退来降低错拼风险，不承诺与全像素检查在任意输入上等价。
- 滚轮和方向键只提供上下方向提示，不把滚轮距离直接当作像素位移。
- 固定栏由相邻帧同位置不变的边缘识别；延伸时从对应边缘寻找连续一致接缝，替换旧固定栏，保留首屏顶部和末屏底部。内部回滚保留已有像素。
- 结果高度不变时，边缘懒加载仍能更新像素和预览；预览按内容修订号更新。
- 无法可靠定位时不更新已拼结果或位置。可以滚回已有内容附近重新接上；跳过整个重叠区域后，仅等待不能恢复遗漏内容。
- 纯色、完全重复列表、动画、较大固定区域仍可能无法定位或出现歧义。建议避开这些区域，缓慢滚动，并检查最终接缝。

## 采集与生命周期

- 采样严格串行，活动期间在上一轮完成后等待 100ms，连续一秒无画面变化或输入后降为 300ms；实际周期还包含抓屏和拼接耗时。每帧直接尝试拼接，不因新滚轮事件重置提交等待。短暂不匹配只保留结果，持续 600ms 才显示警告。
- 保留现有 Electron `desktopCapturer` 串行抓屏、Windows 窗口捕获排除、选区穿透和授权校验，不增加依赖。
- 鼠标移出选区暂停采集。Windows 窗口形状在选区处留孔，其余遮罩接住点击；页面与原生完整左键单击共用幂等结束流程。选区内点击、跨边界拖动和启动按钮残留释放不结束采集。
- 穿透状态通过每 16ms 查询屏幕 DIP 坐标、仅在跨越选区边界时切换；启动及后续切换均不启用 `setIgnoreMouseEvents` 的 `forward`，避免向遮罩额外转发高频鼠标移动事件。滚轮、Escape 和完整左键单击仍沿用原生输入监听。
- 输入使用屏幕 DIP 坐标核对，结束、取消、授权失效和异常时移除监听并恢复窗口状态。手动采集不强制激活目标、不模拟点击或发送滚轮。
- 系统关闭“悬停时滚动非活动窗口”或应用只响应焦点输入时，可在选区内点击目标后再滚动。鼠标移动到其他窗口或目标窗口移动、被遮挡时停止。
- 单击结束后继续尝试拼接惯性滚动中的尾帧，两次采样一致且匹配成功时直接交付，最多等待 1.8 秒。没有二次确认后，尾帧超时、窗口变化、授权失效及其他采集异常均明确失败，不静默交付此前的部分长图。抓屏迟到不能恢复任务或重复完成。
- 实时预览参照上游 `main/stitch/scroll_window.py` 的 PreviewPanel：默认宽 190 DIP，优先在选区右侧底边对齐，再回退左、上、下，并避让独立白色提示条。高度随长图增长，最多占屏幕高度减 60 DIP；空间不足时收窄或隐藏，不把浮层放进穿透选区。
- 预览使用半透明底色、8 DIP 圆角和绿色当前画面框，不绘制预览外框或悬浮边框，预览与状态条均不显示悬浮提示。绿色框只表示当前画面范围，不是定位按钮。长图超出可视范围时保持比例，仅在绿框接近边缘时跟随，上下裁切处显示渐隐和箭头；回滚即使不增加高度也更新位置。主进程只生成当前可见片段，不将整张长图缩成不可读的细条，也不通过 IPC 反复传送整张长图。
- 完整像素分段保存，最终才合并编码；任务结束或取消后释放内存。

最长采集两分钟，高度不超过 30000 像素，总计不超过 4000 万像素，最终 PNG 不超过 50 MiB。主进程改动后需完整重启 Electron。

## 验证

`node --experimental-strip-types scripts/run-tool.ts tsx test/probe-screenshot-window-snap.ts` 使用内存矩形和原生接口替身检查前后层级命中、负坐标跨屏裁剪、无效窗口过滤、遍历循环保护和原生失败时的手动框选回退，不读取真实桌面或启动窗口。实际窗口边界、不同 DPI 显示器及单击/拖动交互由用户手动验证。

`node --experimental-strip-types scripts/run-tool.ts tsx test/probe-screenshot-pointer.ts` 在内存中加载真实遮罩路由，使用窗口、鼠标坐标和定时器替身检查负坐标选区边界、穿透切换去重、不转发鼠标移动、遮罩点击判定、停止及异常清理；不启动窗口或监听真实输入，不代表鼠标卡顿已通过实机验证。

`node --experimental-strip-types scripts/run-tool.ts tsx test/probe-screenshot-completion.ts` 在内存中加载真实窗口及采集控制器，使用窗口、采集、拼接和计时替身检查结束后直接交付、禁止采集中确认普通选区、重复结束、尾帧超时、采集异常、取消、授权失效及旧任务迟到回调；不访问桌面、剪贴板、账号或后端，不代表真实截图交互及拼接效果已验证。

以下为历史验证记录，其中的 `scripts/test-*` 脚本当前不在仓库中，不能直接运行或视为已通过。后续重新编写时统一放在 `test/` 并更新命令，不再放入 `scripts/`。

`node --experimental-strip-types scripts/run-tool.ts tsx scripts/test-screenshot-scroll.ts` 使用内存生成的图像，检查双向扩展、回滚、固定栏、无重叠拒绝与恢复、滚动条干扰、同高度懒加载更新、尺寸边界、预览贴边布局、回滚跟随和可见片段采样。它不启动窗口、不捕获屏幕、不连接后端、不读取账号。

`node --experimental-strip-types scripts/run-tool.ts tsx scripts/test-screenshot-capture.ts` 在内存中编译真实采集控制器，用原生接口替身和假时钟验证持续滚动即时增长、惯性尾帧补采、慢抓屏串行、取消后的迟到帧及结束超时。它不捕获真实屏幕或启动桌面窗口。

`node --experimental-strip-types scripts/run-tool.ts tsx scripts/test-screenshot-hybrid.ts` 检查常规双向滚动零完整哈希、空白和重复列回退、采样列外像素复核、失败不移动基准及旧片段缓存。追加 `--benchmark` 使用同一批 16 张 1280 × 720 合成纹理/文字状帧，对比同一个 TypeScript 拼接器的混合模式和完整指纹模式；先预热，再取五轮中位数，每轮逐像素核对结果。不以耗时作为通过阈值，也不将结果描述为原版 Rust 库或真实界面的性能。计时包含签名提取、定位及分段合成，不包含桌面抓屏、PNG 编码、IPC 和渲染。

`npm run check` 检查类型和格式；`npm run build:electron` 检查主进程构建。上述检查不代表真实桌面、多显示器 DPI、平滑滚动或不同应用的交互已验证，界面效果仍需手动验证。
