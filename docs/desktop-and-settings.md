# 桌面与设置

## 主窗口生命周期

应用启动先显示登录窗口，完成授权与工作台初始化后交接到聊天窗口。窗口提供拖动、最小化、适用的最大化或还原、置顶及关闭操作。

已登录工作台点击关闭会隐藏窗口，保留当前账号、实时消息接收和传输任务。登录窗口关闭则退出应用。重复启动由单实例逻辑恢复已有窗口，不创建另一套数据库连接和消息服务。

## 系统托盘

托盘使用应用图标。点击、双击或选择“打开 OpenChat”恢复当前窗口；“退出 OpenChat”执行完整退出，关闭窗口、连接和媒体任务。

有需要提醒的未读会话时，托盘图标闪烁。鼠标悬浮显示未读浮层，列出头像、名称及未读数。点击会话恢复工作台并进入对应会话及未读位置。

浮层不抢焦点，离开后延迟收起；最多按四行高度展示，更多会话可滚动。托盘右键菜单打开期间不同时展示悬浮预览。

“暂不处理”仅暂停本次授权中的提醒，不标记消息已读。新的消息首次落库且对应会话仍有未读时可以恢复提醒；普通头像刷新和重复消息不会重新开启提醒。

退出、重载、切换账号或授权失效时清理浮层和快照。托盘窗口只接收受控展示数据，不直接查询任意账号记录。

## 独立窗口

| 窗口                 | 入口与作用                                               |
| -------------------- | -------------------------------------------------------- |
| 独立聊天             | 会话右键或拖出会话，绑定一个房间并复用聊天输入和消息流程 |
| 聊天记录             | 聊天标题或详情中的历史入口，搜索本地会话记录             |
| 图片预览             | 图片消息或草稿，提供查看、变换和文字识别                 |
| 视频播放             | 本地可用的视频消息，播放及进度恢复                       |
| 添加朋友             | 会话列表更多菜单，查询目标及进入申请                     |
| 申请与验证           | 添加好友或新的朋友，提交对应表单                         |
| 好友资料             | 聊天详情头像或群成员头像，展示资料和适用操作             |
| 备注与标签           | 好友资料入口，编辑备注字段                               |
| 注册头像裁剪         | 注册表单选图后的裁剪                                     |
| 通话与设备菜单       | 来电或呼出，媒体控制及设备选择                           |
| 截图                 | 输入区入口，屏幕选区和滚动采集                           |
| 设置、更新与更新确认 | 更多菜单中的设置及版本操作                               |

子窗口按用途绑定账号、房间、消息或请求上下文，使用专属 preload。退出或上下文失效后不再接受旧窗口操作。独立聊天不自行恢复账号或创建第二条资源 SSE，历史窗口不开放普通发送权限。

## 共用菜单

普通右键、三点和导航菜单经 `src/services/context-menu/` 统一调用。桌面预热一个独立菜单窗口，关闭时清空内容并隐藏供后续复用。

来源页面只传递白名单展示数据；结果按请求编号交回原页面执行。菜单窗口不拥有业务回调、任意数据库读取或账号恢复权限。浏览器模式使用页面内菜单。

## 设置

当前实际接入的桌面设置功能为：

| 功能     | 行为                                                 |
| -------- | ---------------------------------------------------- |
| 账号资料 | 显示当前授权账号的头像、昵称和 UID                   |
| 退出登录 | 通过确认对话框调用统一退出流程                       |
| 日志等级 | 读取和保存 `error`、`warn`、`info`，立即更新日志过滤 |
| 版本信息 | 显示 `package.json` 中的应用版本                     |
| 检查更新 | 调用版本服务，发现新版本后打开独立更新窗口           |

登录前另有“本次运行记住账号”和 Debug 模式设置。记住账号的行为见 [账号与认证](authentication.md)；Debug 开关由桌面启动和诊断逻辑使用。

本说明仅列出已有处理逻辑的设置。页面中的静态展示项不作为可执行的配置能力。

## 图标与公共资源

应用默认图标来自 `public/ico/openchat.ico`，供窗口、托盘及安装配置使用。部分会话或资料窗口可以使用对应头像；头像缺失时回退到默认图标。

开发及 `npm start` 由依赖中的 Electron 可执行文件启动，系统进程视图可能仍显示 Electron 图标。安装包中的程序图标由 Windows 打包配置生成。

公共头像、音效、通话图形和降噪资源统一通过公共资源路径读取。安装布局见 [Windows 发布与更新](windows-updates.md)。

## 源码定位

| 路径                                                      | 职责                       |
| --------------------------------------------------------- | -------------------------- |
| `electron/pages/workspace/main.ts`                        | 窗口、授权、IPC 与退出编排 |
| `electron/services/runtime/application-tray.ts`           | 托盘、闪烁和恢复主窗口     |
| `electron/pages/tray-preview/`、`src/pages/tray-preview/` | 未读浮层与专属桥接         |
| `electron/pages/context-menu/`、`src/pages/context-menu/` | 共用菜单窗口               |
| `electron/pages/settings/`、`src/pages/settings/`         | 设置、账号与版本入口       |
| `electron/pages/update/`、`src/pages/update/`             | 更新说明、下载和确认       |
| `electron/services/logging/`                              | 日志与诊断支持             |

日志文件见 [数据与存储](storage.md)，更新流程见 [Windows 发布与更新](windows-updates.md)。
