# 联系人与群组

## 通讯录

通讯录按联系人、群聊和新的朋友分类，支持展开、收起和搜索。好友按首字母分组，可按名称或 UID 过滤；群聊按名称过滤；申请列表在已加载记录中搜索并支持继续分页。

选中联系人或群聊先展示真实资料。点击“发消息”或进入群聊才切换到对应会话；加载错误保留为错误状态，不将失败响应推断成不存在的好友关系。

## 搜索与添加朋友

在会话列表的更多菜单打开“添加朋友”，输入手机号或邮箱号进行查询。结果展示目标资料及已确认的关系状态：

- 已有好友可直接发消息，并通过适用入口发起语音或视频通话。
- 非好友通过“添加到通讯录”进入独立申请窗口。
- 本人、查询无结果和查询失败分别处理，不自动发起好友申请。

申请窗口编辑邀请说明、备注和标签后提交；成功表示申请已经发出，是否成为好友仍取决于对方验证。重新搜索、关闭窗口或切换账号后，旧结果不再具有操作权限。

## 好友申请与验证

“新的朋友”显示收到和发出的申请、邀请语、资料、状态和未读标记。收到的待处理申请可以进入验证窗口；发出的申请不能执行接收方审批。

验证提交、申请阅读和未读查询通过各自接口完成。提交期间显示忙碌状态，失败保留表单内容供继续处理；收到资源通知后刷新相应列表和关系资料。

## 资料、备注和关系管理

好友资料可在通讯录详情中查看，也可从单聊头像或群成员头像打开独立资料浮窗。浮窗绑定原目标和当前授权，按本人、好友、非好友显示适用操作。

备注窗口支持备注名、标签、电话和描述，检测实际修改后提交。取消时不保存未提交内容；保存结果用于更新名称和资料展示。

加入黑名单需要确认，移出黑名单通过对应操作恢复。删除联系人需要确认，并可选择同时清空聊天记录；好友关系变更与聊天记录清理分别执行。

## 创建群聊

通过工作台群创建入口选择好友并提交。客户端允许一次选择 1 至 100 位好友，对重复 UID 去重；提交不指定群主或群成员角色，最终成员及群资料以服务端返回为准。

创建成功后取得真实 `groupId`、`roomId` 和群资料，再更新通讯录与会话。网络失败不会自行重复创建群。

## 群资料与成员

群列表显示群名、成员数量和头像。没有独立头像时，可根据真实成员资料展示组合头像。进入聊天详情可分页查看成员，点击头像查看其资料。

具备权限时可以编辑群名称和公告，选择好友加入群，或选择成员移出群。操作结果由服务端核准；客户端权限展示不能代替服务端校验。群成员变更可生成对应的系统消息。

## 退出与解散

普通成员和管理员使用退出群聊操作；群主使用解散群聊操作。角色未知时不开放相应操作。

退出和解散使用不同接口，成功后更新群和会话的可用状态。离群历史仍可保留在本地，不将离群直接等同于删除聊天记录；已经离开的群不能继续按有效成员身份发送消息或管理成员。

群通话邀请及加入规则见 [音视频通话](rtc.md)。

## 接口索引

| 接口范围                                                | 用途                 |
| ------------------------------------------------------- | -------------------- |
| `/capi/user/target/info`                                | 查找用户及公开资料   |
| `/capi/user/friend/page`、`/info`                       | 好友列表与资料       |
| `/capi/user/friend/apply`、`/apply/page`                | 发起申请与申请分页   |
| `/capi/user/friend/agreeApply`、`/replay`               | 好友申请验证相关请求 |
| `/capi/user/friend/apply/unread`、`/apply/read/{id}`    | 申请未读与阅读       |
| `/capi/user/friend/remark`                              | 更新备注资料         |
| `/capi/user/friend/black/{room}`、`/unBlack/{room}`     | 黑名单操作           |
| `/capi/user/friend/del/{room}`                          | 删除联系人           |
| `/capi/group/create`、`/page/group`                     | 创建和查询群聊       |
| `/capi/group/page/groupMember/{roomId}`                 | 群成员分页           |
| `/capi/group/update`、`/members/add`、`/members/remove` | 群资料和成员管理     |
| `/capi/group/exitGroup/{room}`、`/delGroup/{room}`      | 退出与解散           |

表中同一单元格的缩写路径沿用首个路径的业务前缀；完整路径和请求体以 `shared/contacts/` 为准。
