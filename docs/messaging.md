# 聊天与消息

## 工作台与会话

登录后的工作台由导航栏、最近会话或通讯录列表、聊天或资料详情区组成。最近会话展示头像、名称、末条消息摘要、时间和未读数，支持搜索、键盘选择与虚拟列表。

会话类型包括单聊、群聊和服务端提供的文件助手。列表通过远端会话接口同步，在本地内容库中保存摘要及状态；文件助手沿用实际消息和附件流程。

会话支持置顶、免打扰、隐藏、清空记录及独立窗口。群聊详情还提供成员、公告和群管理入口，见 [联系人与群组](contacts-and-groups.md)。

| 操作         | 行为                                                                                     |
| ------------ | ---------------------------------------------------------------------------------------- |
| 置顶         | 提交明确的目标状态，刷新会话顺序                                                         |
| 免打扰       | 同步到后端并保存在本地；提醒和未读汇总使用该状态                                         |
| 隐藏会话     | 从当前会话列表移除，保留本地历史                                                         |
| 清空聊天记录 | 本地清理并记录当时的删除边界，向服务端同步；离线时等待重连，不把后续新消息纳入旧删除范围 |
| 独立窗口显示 | 通过右键菜单或拖出会话打开绑定的单会话窗口，复用工作台消息与输入能力                     |

## 消息类型

| 类型           | 功能                                               |
| -------------- | -------------------------------------------------- |
| 文本           | 编辑、多行输入、发送、复制、引用及适用的撤回和删除 |
| 图片           | 草稿、上传、显示、独立预览、收藏表情、OCR          |
| 视频           | 封面、时长、上传状态、下载、独立播放及进度恢复     |
| 文件           | 文件名和大小、上传状态、下载、另存为及定位本地文件 |
| 语音条         | 录制、上传、时长显示、播放和停止                   |
| 图片表情       | 收藏列表发送、显示、删除收藏及调整收藏顺序         |
| 通话记录       | 显示通话结果、时长及适用的回拨入口                 |
| 系统消息       | 显示服务端产生的群成员变更等提示                   |
| 上传及撤回状态 | 表示正在传输、已取消上传或已撤回的消息状态         |

输入区支持 Enter 发送、Shift+Enter 换行，并避免在输入法组词期间误发送。引用草稿和附件草稿可独立取消；媒体限制和操作详见 [媒体与附件](media-and-files.md)。

## 发送、确认与重试

发送先创建当前账号和会话内的本地待发送记录，再向消息接口提交 `clientMsgId`。HTTP 请求成功表示接口已接收请求；普通消息的确认由资源事件或后续历史状态核对完成，不直接伪装成已送达。

客户端通过房间、发送者和客户端消息标识关联本地记录与服务端消息，避免重复展示。文件与视频使用临时消息协议，在上传期间保持同一条记录，完成后由最终消息替换。

离线和明确请求超时产生的可重试记录由重试队列管理。真实连接恢复后分批处理，每轮连接对同一条消息只尝试一次，手动重发与自动重试共享并发保护。业务拒绝保留实际错误，不作为无限重试任务。

## 接收与同步

桌面主进程为当前账号维护一条资源 SSE 连接，主窗口和子窗口共享事件。连接中断采用退避重连；会话失效时结束连接并清理授权。

接收消息经类型及归属校验后写入本地，再更新摘要、未读和相关窗口。历史接口用于补齐会话消息，已缓存消息的状态还可单独核对，以更新撤回、取消上传等终态。

实时连接状态与账号认证状态分别管理。暂时离线时可以查看当前已授权账号的本地历史；首次登录或恢复授权仍需要后端校验。

## 引用、撤回和删除

引用保存原消息 ID，并显示原文或媒体摘要。点击引用可定位目标，再返回引用发起位置；失效原文显示相应状态，不递归展开整条引用链。

撤回通过服务端消息流程执行，权限由后端核定；群成员撤回入口还受会话权限约束。客户端等待 SSE 或历史状态确认后替换正文。本人已确认撤回的文本可通过“重新编辑”回填所属会话草稿，不自动发送。

单条“删除”作用于当前客户端的本地记录，不影响服务端或其他设备。可删除已确认的文本、图片、视频、文件、语音、表情和通话记录，不受消息发送者或年龄限制。该操作与撤回、整段会话清空具有不同范围。

## 未读与消息定位

会话未读数与已读游标保存在本地，并与服务端快照协调。阅读观测、已读上报及确认分别处理；网络恢复后可继续同步待确认游标。

聊天区提供未读定位、回到底部和引用返回入口。查看历史搜索结果不会推进普通聊天的已读状态。免打扰会话不会按普通会话参与相同的提醒汇总。

## 历史窗口与长记录

聊天标题或详情中的历史入口打开绑定当前会话的独立窗口，支持关键词、消息类型、日期筛选和分页，每页 50 条。查询覆盖本地已保存的该会话历史，不限于当前聊天区已加载的消息，也不承诺搜索服务端未缓存内容。

历史窗口复用消息内容组件，可以查看适用的媒体及引用；窗口权限不包含普通消息发送、删除或任意账号查询。同一会话重复打开时复用已有窗口，切换主窗口会话不会改变已打开历史窗口的绑定。

主聊天使用 `BubbleList` 虚拟滚动，并按视口回收正文。首次读取及更早历史按批加载，前插记录保留阅读位置。详细策略见 [消息正文缓存](message-window.md)。

## 接口与源码

主要接口包括 `/capi/chat/contact/list`、`/capi/chat/contact/info/{roomId}`、`/capi/chat/msg`、`/capi/chat/msg/page`、`/capi/chat/msg/state`、`/capi/chat/msg/temporary` 和 `/capi/resource/sse`。会话偏好使用 `read`、`notDisturb`、`remove`、`hide` 等对应路径，具体请求以共享协议为准。

| 路径                                                  | 职责                                     |
| ----------------------------------------------------- | ---------------------------------------- |
| `src/pages/workspace/ChatWorkspace.vue`               | 会话选择、草稿、发送、事件与生命周期编排 |
| `src/pages/workspace/conversations/`、`conversation/` | 列表、标题和详情                         |
| `src/components/chat/messages/`、`composer/`          | 消息展示、定位和输入                     |
| `src/services/chat/`                                  | 排序、正文缓存、重试、撤回与未读控制     |
| `src/pages/history/`、`src/pages/conversation/`       | 历史及独立聊天窗口                       |
| `electron/services/chat/`、`network/`                 | 发送、历史、已读、删除同步及 SSE         |
| `shared/chat/`                                        | 消息类型、请求、会话和消息状态协议       |
