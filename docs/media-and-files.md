# 媒体与附件

## 草稿与发送

聊天输入区可通过文件选择、拖放、粘贴和截图加入适用的媒体草稿。文件按内容类型和大小进入图片、视频或普通文件流程；准备阶段显示读取、分析和处理进度。

草稿绑定当前账号、会话及来源窗口。移除草稿会释放预览和临时句柄，不删除用户选择的原文件；发送后进入消息流程。退出账号、授权失效或清理所属会话时释放关联任务。

| 类型     | 当前客户端限制                                        |
| -------- | ----------------------------------------------------- |
| 图片     | 单张最多 50 MiB；最多 10 张草稿，草稿合计最多 200 MiB |
| 视频     | 单个最多 2 GiB；最多 3 个草稿，合计最多 6 GiB         |
| 普通文件 | 单个最多 6 GiB；最多 3 个草稿                         |
| 语音条   | 1 至 120 秒，单声道 16 kHz PCM WAV                    |

超过图片或视频专用上限、但仍符合普通文件条件的附件可进入普通文件流程。服务端和对象存储还可能施加自身限制。

## 图片

图片草稿显示缩略图，点击后打开独立预览。移除或发送草稿后，对应临时预览随草稿生命周期关闭。普通图片上传先申请资源上传地址，再传输字节并提交消息。

已保存图片可在聊天或历史中打开预览，支持缩放、平移、旋转、适应窗口、全屏和相邻图片导航。相邻导航限定于当前会话已缓存的图片，草稿预览使用独立上下文。

图片预览通过主进程按消息或草稿标识读取，不接受页面任意指定本机路径。文字提取与图片选区见 [图片文字识别](image-ocr.md)。

## 普通文件

文件消息显示名称、大小、上传进度和状态。发送过程先创建服务端临时消息，再通过对象存储分片上传，完成后替换临时记录。失败可在适用状态下重发，取消向服务端提交取消状态。

下载使用消息和会话标识申请短期资源授权。业务 JWT 只用于业务接口，不随对象存储字节请求发送。文件在本地缺失时展示下载入口，用户点击后才下载；另存为、定位目录和拖出操作使用已经可用的本地文件。

资源状态探测只使用 HEAD，不为探测下载整个文件。服务端明确返回 404/410 时展示过期状态；探测网络错误保留下载入口。点击下载后的统一失败文案不能被当成服务端已删除文件的证明。

文件记录与附件副本不同：存储层文件记录保存元数据及路径，删除记录不会删除磁盘原文件，原文件移动后该路径可能失效。更多菜单中的“聊天文件”当前进入已有文件助手会话，不是独立文件管理器。

## 视频

视频入口识别 MP4、MKV、AVI、MOV、WMV、FLV、WebM、MPG 和 MPEG，随后校验容器内容并用 FFprobe 读取元数据。扩展名可识别不代表任意损坏文件或编解码组合都可以播放。

主进程负责封面、兼容处理及上传来源管理，使用 FFmpeg 和 FFprobe。视频按 16 MiB 分片上传，界面展示准备与上传状态，支持适用的取消和重发。

发送期间的临时消息保存文件信息和封面，传输完成后由最终确认更新。其他设备的数据库副本不会自动取得当前安装的上传来源权限。

视频下载后打开独立 Artplayer 播放窗口。播放器使用受控本地媒体协议，保存和恢复播放位置，提供从头播放和失败重试；读取失败不会自动改为任意远端 URL。

## 语音条

输入区主动申请麦克风权限后开始录音，展示实际波形、计时和接近上限时的提示。录音可以取消；达到 120 秒结束采集。

音频编码为 16 kHz、单声道 PCM WAV，上传成功后交由工作台创建消息。取消或退出会关闭麦克风、采样和计时；原始录音不作为临时文件持续保存。

语音消息按绑定消息读取音频，显示秒数和播放动画，支持播放及停止。语音条与普通音频文件具有不同的消息协议。

## 表情

输入区提供内置表情和收藏图片表情。内置表情可插入文本草稿；收藏图片以独立表情消息发送，不清空原文字草稿。

普通图片及表情消息可通过适用的右键菜单添加到收藏。收藏列表读取本地缓存并刷新远端，支持删除和移到最前；提交与展示分别维护忙碌和错误状态。

收藏接口包括 `/capi/user/emoji`、`/list`、`/delete` 和 `/front`。上传、消息提交和收藏是不同操作，不以收藏成功代替消息发送。

## 复制、另存与拖出

消息组件按内容类型提供复制和本地文件操作。桌面主聊天中的普通图片、视频和文件可将已存在的本地附件拖到桌面或文件夹，保存副本而不移走缓存或原文件。

拖出前仅准备本地附件与图标，不触发隐式远端下载。上传临时状态、已撤回消息和无有效本地来源的消息不能按正常附件拖出。浏览器、历史和独立聊天窗口的入口能力受各自桥接权限限制。

主进程复核窗口、当前授权、消息归属及本地路径，短期拖拽凭据在退出、重载或授权失效后作废。

## 源码定位

| 路径                                                        | 职责                                   |
| ----------------------------------------------------------- | -------------------------------------- |
| `src/components/chat/composer/`、`attachments/`             | 草稿、进度、录音与附件卡片             |
| `src/components/chat/messages/`                             | 图片、文件、视频、语音和表情消息       |
| `src/pages/image-preview/`、`src/pages/video-player/`       | 独立媒体窗口                           |
| `src/pages/workspace/emoji/`                                | 收藏列表、排序与刷新                   |
| `src/services/media/`                                       | 图片来源、视频队列、音效和语音播放     |
| `electron/services/media/`                                  | 文件来源、上传、缓存、转码、草稿与 OCR |
| `electron/services/chat/message-copy.ts`、`message-drag.ts` | 原生复制及附件拖出                     |
| `shared/media/`、`shared/chat/emoji.ts`                     | 媒体类型、限制与协议                   |

附件磁盘目录和备份范围见 [数据与存储](storage.md)。
