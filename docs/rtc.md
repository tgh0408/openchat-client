# 音视频通话

## 发起与接听

单聊标题栏和适用的好友资料入口提供语音、视频呼叫。创建呼叫成功后打开绑定 `callId` 的独立通话窗口，显示对方资料、呼叫状态和操作。

来电通过已有资源 SSE 分发。用户可以接听或拒绝，呼出期间可以取消，通话建立后可以挂断。窗口根据服务端状态和版本处理结果，迟到事件不能恢复已经结束的呼叫。

聊天中的通话记录展示结果与时长，并提供适用的回拨入口。需要强制呼出的场景先显示确认对话框，取消不会继续呼叫。

## 群通话

从群会话进入通话时，先查询当前群是否存在活动呼叫：

- 已有呼叫时沿原 `callId` 加入；退出、拒绝或邀请过期的成员可在服务端允许时重新进入。
- 明确没有活动呼叫时，选择群成员后创建新的呼叫。
- 当前设备已经参与时打开原通话窗口；其他设备仍在参与时不自动抢占。
- 查询失败显示错误，不直接创建另一场群通话。

群面板展示真实成员、邀请等待、发言状态和媒体画面。群视频开关通过服务端席位接口确认，再更新摄像头状态。发起群通话时的成员选择与通话进行中的成员操作是不同流程。

## 连接与媒体

通话控制通过 HTTP API 和资源 SSE 完成。单聊支持原生 WebRTC 直连协商，LiveKit 用于相应的 SFU 媒体连接；采用哪条媒体路径由服务端协商结果和当前呼叫决定。

直连到 SFU 的切换需要服务端确认，不能仅以本地状态宣称双方完成切换。WebRTC Offer/Answer、连接状态、媒体轨道和失败恢复由通话服务统一管理。

通话服务需要配套后端信令、可访问的媒体服务和权限可用的输入输出设备。`VITE_RTC_SERVER_URL` 负责页面连接许可，实际加入凭证和 `serverUrl` 由后端返回。

## 设备与音频

麦克风、扬声器和摄像头使用独立设备菜单，展示真实设备列表及当前选中状态。

| 控制             | 行为                                         |
| ---------------- | -------------------------------------------- |
| 麦克风开关       | 控制本次通话发送音频的静音状态               |
| 麦克风设备       | 新设备采集成功后替换输入；失败保留原状态     |
| 输入音量         | 调节当前通话发送增益，不修改系统总音量       |
| 扬声器开关与音量 | 控制实际远端播放元素的静音和音量             |
| 输出设备         | 切换实际播放设备，成功后更新选中项           |
| 摄像头开关与设备 | 按权限启停或替换视频输入，不附带音频音量控制 |

设备切换期间仍可以挂断。权限拒绝、设备被占用、设备断开和切换失败会显示对应错误，菜单不会只更新视觉状态而跳过实际设备操作。

音频处理使用 DeepFilterNet3 降噪资源，资源位于 `public/rtc-noise/`。降噪图、输入增益、静音和设备替换在同一通话生命周期中管理。视频质量策略按连接统计调整质量档位。

## 恢复与结束

登录后发现可恢复呼叫时，显示继续连接或挂断的确认。重新加入成功后才处理旧窗口和重新初始化媒体，不依靠旧窗口的内存状态恢复授权。

挂断、拒绝、取消、关闭相关通话或授权失效后，释放采集轨道、媒体连接、音频图、设备菜单和事件订阅。通话页面复用主进程的资源事件，不新建第二条资源 SSE。

## 接口与源码

主要接口为 `/capi/rtc/calls`、`/capi/rtc/calls/{callId}`、对应的 `accept`、`reject`、`cancel`、`expire`、`hangup`、`leave`、`token`、`media`、`video` 和 `reconnect` 路径，以及 `/capi/rtc/rooms/{roomId}/active`。请求携带幂等标识或预期版本的操作以共享协议为准。

| 路径                                                    | 职责                                         |
| ------------------------------------------------------- | -------------------------------------------- |
| `src/pages/workspace/rtc/`                              | 呼叫入口、群成员选择协调、回拨和恢复确认     |
| `src/pages/workspace/dialogs/RtcInviteMemberDialog.vue` | 发起群通话时选择成员                         |
| `src/pages/rtc/RtcCallWindow.vue`                       | 通话状态、面板、媒体及窗口编排               |
| `src/pages/rtc/panels/`                                 | 单聊语音、单聊视频和群通话面板               |
| `src/pages/rtc/device-menu/`                            | 设备列表及音量菜单                           |
| `src/pages/rtc/services/`                               | RTC API、直连、LiveKit、降噪、输出与质量控制 |
| `electron/pages/rtc/`                                   | 呼叫窗口、专属桥接与设备窗口                 |
| `shared/rtc/`                                           | 呼叫状态、媒体协商、设备及事件协议           |
