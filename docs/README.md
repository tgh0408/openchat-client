## 阅读顺序

首次运行从 [运行与构建](getting-started.md) 开始，接入后端时参阅 [账号与认证](authentication.md) 和各模块的接口说明。维护代码时通过 [项目结构](project-structure.md) 定位对应页面与服务。

源码目录内的 README 用于就近定位组件；模块的完整功能说明集中在本目录。未接入的页面展示项不作为已实现能力列出，当前影响安装包交付的缺失项单独记录在发布文档中。
