# 桌面截图

## 区域截图

在聊天输入区打开截图入口，可选择保留或隐藏当前聊天窗口。截图覆盖层按显示器展示屏幕快照，支持自由框选、移动和缩放选区。

Windows 支持顶层窗口吸附：悬停预览候选窗口边界，首次单击锁定选区，拖动则进入自由框选。锁定后可继续调整，再通过确认按钮、双击或 Enter 完成；右键、取消按钮或 Escape 取消普通截图。

跨屏窗口仅选择当前显示器范围内的部分，不自动拼接多屏。候选边界来自当前屏幕快照对应的窗口信息，不恢复被遮挡内容，也不识别窗口内部控件。

成功截图进入原会话的图片草稿，并沿用剪贴板复制流程，不自动上传或发送。点击草稿缩略图可打开独立图片预览。

## 滚动截图

1. 框选目标窗口的可滚动区域，避开大面积固定栏和动态内容。
2. 点击“滚动截图”，把鼠标移入选区，在目标应用中手动向上或向下滚动。
3. 查看实时长图预览；可从页面中间开始向两端扩展，回滚到已有区域只更新位置，不重复追加。
4. 单击选区外的遮罩或预览面板结束采集，尾帧确认后直接返回图片草稿。

滚动过程中 Escape 取消整个任务，回车不结束采集；方向键和滚轮仍交给原目标窗口。鼠标移出选区暂停采集，移回后继续。当前实现为手动纵向滚动，不提供自动发送滚轮的操作。

结束时会继续采样惯性滚动的尾帧。尾帧无法确认、目标窗口变化或授权失效会明确失败，不静默交付未经确认的部分结果。

## 预览与拼接

预览随拼接内容增长，并用绿色框标示当前画面位置；长图超过预览可用高度后随当前区域移动。预览不是跳转原页面的控制器。

拼接先按稀疏列特征查找位移，再通过局部像素和接缝校验；快速匹配不能确认时回退到完整行指纹与已有片段定位。滚轮只提供方向提示，不按滚动次数推算像素距离。

固定栏和回滚通过已有内容匹配处理。没有可靠重叠时保留已确认结果，可滚回已有内容附近继续；纯色区域、重复列表、动画和遮挡可能造成歧义。最终仍应检查长图接缝与内容完整性。

## 平台与资源边界

Windows 滚动截图依赖窗口捕获排除、鼠标穿透和原生输入监听。保留遮罩且排除捕获需要 Windows 10 2004 对应的内部版本 19041 或更新环境；捕获排除不可用时会拒绝继续相应操作。

窗口吸附不可用时普通截图仍可手动框选。实际采集结果受系统捕获能力、应用保护和窗口内容影响。

| 限制         | 上限       |
| ------------ | ---------- |
| 单次滚动采集 | 两分钟     |
| 长图高度     | 30000 像素 |
| 图像总像素   | 4000 万    |
| 输出 PNG     | 50 MiB     |

采集串行执行，像素按片段保存在内存，完成时才合并编码。取消、授权失效、显示器变化和窗口关闭会停止任务、移除监听并释放截图资源。
