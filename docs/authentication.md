# 账号与认证

## 登录与账号选择

启动后显示登录窗口。密码表单支持账号编辑、密码显隐、回车提交和历史账号下拉选择。只有后端确认的账号可以进入工作台。

已有有效会话的账号显示快捷进入入口；用户确认后重新校验身份并打开对应内容库。编辑快捷入口中的账号会切回密码表单。切换账号不会自动注销其他已保存账号，也不会仅凭选中操作打开该账号的数据库。

主进程通过 Electron `safeStorage` 加密保存账号身份和 JWT，写入 `settings.sqlite`。密码不保存；系统安全存储不可用时没有明文保存回退。“本次运行记住账号”控制退出后表单的内存预填，与已保存会话的加密持久化分别处理。

## 注册与头像裁剪

注册表单收集账号、昵称、密码及可选头像，提交到后端注册接口。头像选择后可在裁剪编辑器中调整，桌面端使用独立头像裁剪窗口；确认后将图片字节加入注册表单，取消则保留原表单。

注册使用 `multipart/form-data`，字段为 `userId`、`username`、`password` 和可选 `avatar`。成功注册后回到登录流程，不自动取得登录授权。草稿和密码仅存在当前交互内存中。

头像支持 JPG 和 PNG，按文件头和解码尺寸检查；单张最多 10 MiB、4000 万像素。

## 授权流程

1. 调用密码登录接口，检查业务响应和返回的 `uid`、`token`、`clientSqlPassword`。
2. 调用 `globalUid`，核对后端确认的 UID 与登录身份一致，并取得本次内容库密钥。
3. 加载用户资料，建立当前账号的主进程授权上下文。
4. 用户进入工作台时激活对应内容库，初始化会话和资源事件连接。

`clientSqlPassword` 只保留在主进程授权会话中，不写入持久化登录会话，也不交给渲染页面。UID 和消息等长整型标识在业务内部按字符串处理。

JWT 由后端签发。客户端解码用于格式、身份和可选 `exp` 检查，不代替服务端验签；缺少 `exp` 时不会自行推算过期时间。

恢复保存的账号也要请求后端校验。明确失效或身份不一致时清除该账号令牌并返回登录；断网、超时和服务异常时保留会话并显示重试提示，不把暂时无法校验当成身份已经失效。

## 设备与平台

业务请求统一携带 `clientId` 和 `X-Device-Id`，已登录接口同时携带 Bearer JWT。桌面使用主进程初始化的设备标识摘要及 PC 平台，浏览器使用当前页面内存中的随机设备标识及 WEB 平台。

平台和设备在当前运行期间固定，不因切换账号而更换。系统原始硬件标识不会直接作为请求头提交。平台配置见 [运行与构建](getting-started.md)。

## 退出和授权失效

主动退出会调用服务端退出接口，并清理本机授权、实时连接、账号相关子窗口和媒体任务。服务端撤销请求失败时仍退出本机，同时保留明确的失败提示，不能宣称远端令牌已经撤销。

资源事件通知会话被替换或过期时，客户端终止当前连接并返回登录。旧窗口和旧请求的迟到结果不能继续访问新账号数据。

关闭已登录工作台只隐藏到托盘，仍可接收消息；通过托盘退出应用会完整清理运行资源，并保留可恢复的加密登录会话。关闭登录窗口则结束应用。

## 接口对应

以下是客户端实际调用的主要认证路径，不替代后端的完整接口定义。

| 方法 | 路径                         | 用途                      |
| ---- | ---------------------------- | ------------------------- |
| POST | `/capi/user/public/login`    | 提交 `userId`、`password` |
| POST | `/capi/user/public/register` | 提交注册表单及可选头像    |
| GET  | `/capi/user/globalUid`       | 验证 UID 和内容库密钥     |
| POST | `/capi/user/loginOut`        | 撤销当前登录会话          |
| GET  | `/capi/user/userinfo`        | 获取当前账号公开资料      |
| POST | `/capi/user/target/info`     | 查询目标用户资料          |

## 源码定位

| 路径                                                    | 职责                                     |
| ------------------------------------------------------- | ---------------------------------------- |
| `src/pages/login/`                                      | 登录、注册、账号下拉、启动状态和登录设置 |
| `src/pages/avatar-crop/`、`src/components/avatar-crop/` | 裁剪窗口和复用编辑器                     |
| `src/services/auth/auth.ts`                             | 页面认证调用及浏览器侧状态               |
| `electron/services/auth/`                               | 可信会话、设备身份、加密保存和访问控制   |
| `electron/pages/login/registration-avatar.ts`           | 注册头像的原生选择与读取                 |
| `shared/auth/`                                          | 认证请求、解析、设备和头像协议           |

数据库与会话保存范围见 [数据与存储](storage.md)。
