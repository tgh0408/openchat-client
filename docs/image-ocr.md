# 图片文字识别

## 使用入口

在聊天图片、历史图片或图片草稿的独立预览窗口中打开文字提取面板。识别成功后，侧边显示可编辑文本，图片上叠加与原图位置对应的透明文字层。

文字层随缩放、旋转和平移保持对齐，可逐字或跨行选择，并将选区映射到右侧编辑文本。编辑后的内容可复制；编辑草稿只保留在当前窗口，不覆盖识别原文或数据库缓存。

面板打开时切换图片会清除旧显示并为新图片读取缓存或提交识别；面板关闭时切图不主动识别。加载失败、识别不可用和任务取消分别显示对应状态。

## 本地识别

识别使用 `ppu-paddle-ocr`、ONNX Runtime 和本地 PP-OCRv6 medium 模型。主进程只传递经授权读取的图片，解码、缩放、文字检测和识别在独立 Electron utility 进程中完成。

识别过程不依赖网络下载模型，不把图片上传到文字识别服务。普通消息图片本身的读取仍可能需要原有附件下载流程。

开发和安装版均从应用目录的 `public/ocr/` 读取：

| 文件                       | 用途                 |
| -------------------------- | -------------------- |
| `PP-OCRv6_medium_det.onnx` | 文字检测模型         |
| `PP-OCRv6_medium_rec.onnx` | 文字识别模型         |
| `ppocrv6_dict.txt`         | 字典                 |
| `LICENSE-PaddleOCR.txt`    | 随模型分发的许可文本 |

构建脚本检查文件可读且非空，缺失时警告并继续构建其他功能。运行时无模型且无可用缓存时不能发起识别；存在有效缓存的已保存图片可继续读取结果。

## 队列与生命周期

全局维护一个串行后台队列，同一时刻执行一个识别任务。相同图片的重复请求可合并等待，失败后继续处理后续任务。

普通图片窗口切图、收起面板或关闭后，已提交的后台任务可以继续完成；返回同图时可复用任务或缓存。临时草稿绑定来源，来源失效后撤销其任务。明确取消、消息删除、账号失效和退出会清理相应任务。

成功识别后保留模型进程供连续图片复用，空闲 60 秒回收。应用退出不恢复未完成的内存队列；已写入数据库的成功结果可以在重新启动后复用。

## 运算后端

首次需要识别时根据运行库能力选择 GPU 或 CPU。Windows 对应 DirectML，其他平台的实现包含 CUDA 和 CoreML 分支，但这不代表仓库提供了这些平台的安装包。

已确认的后端及时间保存在 `settings.sqlite`。连续 72 小时内的有效记录可复用，过期后在实际识别时重新判断，不在登录阶段加载模型。

GPU 初始化、推理、进程异常或首次尝试超时后，主进程结束旧进程并在新的 CPU 进程中重试一次。总任务预算包含启动、解码、推理及回退；CPU 失败明确报告错误，不无限重试。旧进程尚未退出时不并行堆叠新的推理进程。

## 识别预算

| 项目                | 限制             |
| ------------------- | ---------------- |
| 编码图片大小        | 50 MiB           |
| 原图像素            | 4000 万          |
| 检测长边            | 960 像素         |
| 裁剪源长边          | 最多 2000 像素   |
| 检测框数            | 最多 1000        |
| 识别批量            | 逐框执行         |
| 识别高度 / 最大宽度 | 48 / 3200 像素   |
| 输出文字长度        | 最多 100000 字符 |
| 任务总预算          | 两分钟           |

结果坐标映射回解码后的原图。缩放预算有助于控制资源消耗，但密集小字、极长截图和超宽文本仍可能漏字或降低精度。

## 结果缓存

已保存消息图片按原始图片字节的 SHA-256 缓存在 `database/public.sqlite` 的 `img_orc` 表中。缓存包含原文、行位置、原文偏移和图片尺寸，同字节图片可跨账号、会话和消息复用。

每次读取都先校验当前账号及真实消息的访问资格，再读取原图并计算摘要。页面不能提交任意摘要、路径或 SQL。命中缓存时无需启动模型进程。

成功的无文字结果也会缓存；失败、取消和畸形结果不作为有效缓存。消息撤回或删除后，该消息失去读取资格，但不因此清除其他图片可复用的摘要结果。临时未发送草稿不写入共享缓存。

**共享 OCR 缓存为明文。** 它不保存图片字节和账号、房间、消息 ID，但包含提取文字；当前用户内容库备份不包含它。详细存储范围见 [数据与存储](storage.md)。

## 选区映射

每行结果保存原图坐标和 UTF-16 偏移。图片层使用原生文字选择，编辑区通过 `diff-match-patch` 将原文选区映射到编辑后文本。

插入、替换和删除按差异调整位置；大量重排或整段改写只能近似对应，不保证语义匹配。选区从图片映射到编辑区，不把编辑后的文字重写回图片识别坐标。
